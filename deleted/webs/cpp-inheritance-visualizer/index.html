1. 类关系

继承让 Derived 对象天然包含一个 Base 子对象，所以 Base 指针可以指向 Derived 对象的 Base 那一部分。

struct Base {
  virtual void speak();
  int baseValue;
};

struct Derived : Base {
  void speak() override;
  int derivedValue;
};
继承 解决“能不能当成 Base 使用”。
虚函数 解决“运行时到底调用谁”。
vptr / vtable 是编译器常见的实现方式，不是 C++ 标准强制的语法概念。
