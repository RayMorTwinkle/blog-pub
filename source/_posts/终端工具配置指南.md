# 终端工具配置指南

## 文件清单

| 文件 | 用途 | 放置位置 |
|------|------|---------|
| `fresh-config.json` | Fresh 编辑器配置 | `~/.config/fresh/config.json` |
| `ghostty-config` | Ghostty 终端配置 | `~/.config/ghostty/config` |
| `zshrc` | Zsh shell 配置 | `~/.zshrc` |
| `yazi` | Yazi 文件管理器（无自定义配置，使用默认） | — |

---

## Fresh 编辑器

**是什么**：终端文本编辑器，快捷键和系统一致（Cmd+C 复制、Cmd+Z 撤销），不需要学 Vim。

**安装**：
```bash
brew install fresh
```

**配置文件位置**：`~/.config/fresh/config.json`

**当前配置**：
```json
{
  "version": 1,
  "theme": "dracula",
  "locale": "zh-CN",
  "keymap": "macos"
}
```

**常用快捷键**：
- `Cmd+C` 复制
- `Cmd+V` 粘贴
- `Cmd+Z` 撤销
- `Cmd+X` 剪切
- `Cmd+S` 保存
- `Cmd+F` 搜索

**使用**：
```bash
fresh 文件名              # 打开文件
fresh 文件名:10           # 打开文件并跳到第10行
```

**设为默认编辑器**（在 `~/.zshrc` 中）：
```bash
export EDITOR='fresh'
```

## Ghostty 终端

**是什么**：GPU 加速的现代终端，支持主题、透明背景、分屏。

**安装**：
```bash
brew install --cask ghostty
```

**配置文件位置**：`~/.config/ghostty/config`

**当前配置要点**：
- 字体：Maple Mono NF CN（中文走苹方 fallback）
- 主题：Catppuccin Mocha
- 背景透明度：0.85（带模糊）
- 分屏：`Cmd+D` 左右分屏
- 光标：竖线样式

**重载配置**：`Cmd + Shift + ,`

**常用快捷键**：
- `Cmd+D` 左右分屏
- `Cmd+Shift+Enter` 放大/还原分屏
- `Cmd+Shift+F` 同上

## Yazi 文件管理器

**是什么**：终端文件管理器，类似 Finder 但更快。

**安装**：
```bash
brew install yazi
```

**使用**：
```bash
y                  # 启动（退出时自动 cd 到当前目录）
```

**常用快捷键**：
- `Enter` 进入目录/打开文件
- `Backspace` 返回上级目录
- `q` 退出（自动 cd）
- `Q` 退出（不 cd）
- `Space` 选中文件
- `/` 搜索
- `j/k` 上下移动

**Shell wrapper**（在 `~/.zshrc` 中，已配置）：
```bash
function y() {
    local tmp="$(mktemp -t "yazi-cwd.XXXXXX")" cwd
    command yazi "$@" --cwd-file="$tmp"
    IFS= read -r -d '' cwd < "$tmp"
    [ "$cwd" != "$PWD" ] && [ -d "$cwd" ] && builtin cd -- "$cwd"
    rm -f -- "$tmp"
}
```

## 快速还原

如果配置丢失，把文件复制回去即可：

```bash
cp fresh-config.json ~/.config/fresh/config.json
cp ghostty-config ~/.config/ghostty/config
cp zshrc ~/.zshrc
```
