03 选择填空题：题干和选项都要看全

这一页不再只给答案。每题保留题干、选项、正确答案、错项排除。做题时先圈关键词，再看选项。

总方法

选择题先做 3 件事

1. 圈题干关键词：比如“不能”“不是”“运行时”“const函数”“纯虚函数”。
2. 先自己说一句人话：比如“this 是指针，所以用箭头”。
3. 再看选项：选项很会装，你先有判断，才不容易被带跑。

第7题 构造函数调用时机

下列哪个叙述是正确的（）
A构造函数在声明对象的时候被调用
B构造函数在使用对象的时候被调用
C构造函数在声明类的时候被调用
D构造函数在使用类的时候被调用
A对象一声明，就像“出生”，构造函数马上自动执行。
  • B 错：不是等你使用对象才构造。
  • C/D 错：声明类只是写图纸，不会造对象。

Cint ShowData(void) const { /* statements */ }
DBoth A and B
C成员函数后面的 const 才表示“这个函数不改对象”。
  • A/B 的 const 修饰返回值，不是 const 成员函数。

第30题 显式调用基类函数

应在下列程序划线处填入的正确语句是（）
class Base {
public:
    void fun() { cout << "Base::fun" << endl; }
};
class Derived : public Base {
    void fun() {
        ____________ // 显式调用基类的函数 fun()
        cout << "Derived::fun" << endl;
    }
};
Afun();
BBase.fun();
CBase::fun();
DBase->fun();
C类名加作用域运算符：Base::fun();，就是点名调用父类版本。

第31题 static 输出

以下程序输出为（）
class abc {
public:
    static int w;
    int i;
    abc() { i = ++w; }
};
int abc::w = 1;

int main() {
    abc a, b, c;
    cout << a.w << " " << b.i << endl;
}
A3 1
B4 3
C4 1
D3 3
Bw 是共享的，从 1 变 2、3、4；b.i 是 b 出生时的 3。

template <class T>
T maximum(T value1, T value2) {
    if (value1 > value2)
        return value1;
    else
        return value2;
}
A5 和 类型不匹配错误
B5 和 5.2
C2 和 2.3
D两条错误信息
B第一次 T 推成 int，返回 5；第二次 T 推成 double，返回 5.2。
